# README hero

The README hero was composed with [ProjectMock](https://github.com/elpah/project-mock), using its **Hero Monitor + Phone** layout. It combines two captures of the same fictional Field Lab page from a temporary local HMD instance:

- `screenshots/09-field-lab-desktop.png` — phosphor skin, dark mode, 1440 × 960.
- `screenshots/10-field-lab-mobile-soft-light.png` — soft skin, light mode, 500 × 1084.

The desktop uses the preset's default position. Move the phone to x = 1070, y = 190, set its rotation to 0°, and keep its scale at 1. The final image is the upper-left 1450 × 840 region of the 1600 × 1000 composition. Export it as `hero.png`.

Recapture both views from synthetic content when the HMD interface changes. The mobile image is a genuine responsive view, not a crop of the desktop capture. For capture setup and privacy precautions, see the HMD MCP page `ai/hmd/capturing-screenshots`.
